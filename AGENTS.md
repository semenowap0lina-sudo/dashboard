# AGENTS.md

## Repo at a glance
- `my_package/` is the library (flat layout, not `src/`). The real module is `my_package.my_module` (`MyClass`, `my_function`); `README.rst`'s `my_package.my_module_1` import is stale.
- Python >= 3.10; CI pins 3.10. The local `.venv` is 3.12, which breaks the pinned pylint (see below).
- `tests/` = pytest, `docs/source/` = Sphinx, `examples/` = sample notebook/data.
- `data/` and root `/cache/` are gitignored research outputs. `notebooks/cache/vasileostrovsky_blocksnet.ipynb` is an untracked WIP research notebook.

## Setup
- `python3 -m venv .venv && source .venv/bin/activate` (or `make venv`).
- Install extras with `pip install -e '.[tests]'` / `.[dev]` / `.[docs]` / `.[research]`. The test extra is plural: `tests`.
- `my_package/__init__.py` resolves `__version__` via `importlib.metadata.version("my_package")`, so the package must be installed before importing it; a bare import from an uninstalled clone raises `PackageNotFoundError`.

## Commands
- All tests: `pytest tests`. Single test: `pytest tests/test_1.py::test_my_function`. Coverage: `pytest tests --cov`.
- Format: `isort my_package && black my_package` (or `make format`).
- Lint: `make lint` (pylint).
- Docs: `pip install -e '.[docs]'`, install `pandoc`, then `sphinx-build docs/source docs/build`.
- Build: `python -m build .` (outputs to `dist/`).

## Makefile / CI gotchas (verified)
- `make tests` is a no-op: the `tests/` directory shadows the target and the Makefile has no `.PHONY`. Use `pytest tests`.
- `make test` (called by `.github/workflows/tests.yml`) has no rule, and `make install-test` installs the undefined `.[test]` extra (base package only). CI's test job is currently broken; don't copy its commands.
- `make lint` crashes on Python 3.12 because `pylint==2.17.5` uses the removed `ast.Str`. Run lint under Python 3.10 (as CI does) or expect false failures.
- `make format` / `make lint` only cover `my_package`, not `tests/` or `docs/`.
- `docs/source/guide/testing.rst` still documents `make test` / `make test-cov`; the working equivalents are `pytest tests` / `pytest tests --cov`.

## Conventions
- black, isort, and pylint all use line length 120. isort is configured with `lines_after_imports = 2`, `multi_line_output = 3`, trailing commas.
- Use numpydoc-style docstrings. Sphinx uses autodoc + napoleon and recursively autosummaries `my_package`.
- `README.rst` is included in `docs/source/index.rst` between `.. readme-start` / `.. readme-end` and logo markers. Keep the markers; README edits appear in the docs.
- Package version is generated by setuptools_scm from git tags; don't hardcode it. `docs/source/conf.py`'s `release = "0.0.1"` is a separate hardcoded docs version.
- `pyproject.toml` declares `license = { file = "LICENCE" }` while the file is `LICENSE`; builds warn but succeed. Fix the reference if editing packaging metadata.
- Guide pages under `docs/source/guide/` are in Russian; README is in English.

## Release
- Pushing a `v*` tag triggers `.github/workflows/pypi.yml`: stable tags publish from `main`, pre-release tags (`.dev`/`a`/`b`/`rc`) publish only from `develop`. There is no local `develop` branch.
- Pushes to `main` build docs and deploy `docs/build/` to the `documentation` branch (GitHub Pages).

## Research notebook
- Install `.[research]`; the notebook hard-fails unless BlocksNet is exactly `1.0.0a9`.
- First run downloads OSM layers through Overpass (slow, multiple mirrors) and caches under `data/vasileostrovsky/{raw,processed,results}`. Set `USE_CACHE = False` or `FORCE_REDOWNLOAD = True` to refetch.
- The notebook derives paths from `Path.cwd()` and only strips one trailing `notebooks` level. Run it from the repo root or `notebooks/`; running from `notebooks/cache/` has already created a duplicate `notebooks/cache/data/` tree.
- The notebook's own rerun instructions point to `notebooks/vasileostrovsky_blocksnet.ipynb`, but the only current copy is `notebooks/cache/vasileostrovsky_blocksnet.ipynb` (untracked).
